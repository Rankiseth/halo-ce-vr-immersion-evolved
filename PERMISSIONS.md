# Upstream permission

Halo CE VR - Immersion Evolved is an unofficial community derivative of
[LivingFray/HaloCEVR](https://github.com/LivingFray/HaloCEVR).

On 26 November 2024, LivingFray posted:

> Any other modders are free to fork this/steal the code for other mods if they wish.

- [Original Discord message](https://discord.com/channels/747967102895390741/1311106226133926020/1311106226133926020)
- [Screenshot supplied by the maintainer](docs/permissions/LivingFray-2024-11-26.png)

The screenshot was supplied on 18 October 2026. Its displayed posting time is
4:08 PM; the viewer's timezone is not established by the image. The message
link was supplied separately by the maintainer. Discord content could not be
independently retrieved in the preparation environment; the quotation was
transcribed from the supplied screenshot.

This project records that statement as its basis for reusing LivingFray's code.
It is an informal permission statement, not an MIT, GPL, or LGPL declaration.
No standard project-wide license was found in the upstream repository during
the review. This note does not relicense upstream contributions, dependencies,
Halo game files, or artwork, and does not imply LivingFray endorses this fork.

The upstream README asks that the mod stay on PC and encourages free community
mods. This project targets the original Windows PC game and is planned as a
free community release. See [CREDITS.md](CREDITS.md) and
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for attribution and dependency
terms. Existing notices in individual source files remain in effect.
